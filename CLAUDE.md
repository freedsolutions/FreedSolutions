# FreedSolutions - website

Since 2026-11-02 this repo holds the Freed Solutions landing page (GitHub Pages, www.freedsolutions.com) and nothing else. Skills, the warehouse and the client trees moved to the NewWaveCannabis repo; local-only folders went to the OneDrive archive (`Freed Solutions/Archive/`); git history keeps everything that was tracked here.

## Rules
- Direct push to `main`.
- `index.html` at the root is the live landing page. Do not edit it without confirming the current CTA strategy.
- `brand/` is local-only except the two logo PNGs the page uses.
- `clients/` is local-only (`.gitignore`) and holds nothing since 2026-11-05, when the last client tree moved out. It is not part of this repo.
- No `package.json`, no `node_modules`, no scripts.
